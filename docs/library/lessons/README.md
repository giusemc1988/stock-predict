# Lessons: problem, cause, fix

One file per lesson: `YYYY-MM-DD-short-name.md`. Short. No secrets. Do not rewrite old lessons except to fix a mistake; add a new one.

Template:

    # <short title>
    - **Date / who:** 2026-11-12, claude|milo|hermes-win|hermes-ubuntu|chanh
    - **Problem:** what went wrong, the exact symptom or error text
    - **Cause:** the real reason (write "unconfirmed" if you do not know)
    - **Fix:** what fixed it, or what to do next time
    - **Check:** one command or look that proves it is fine
