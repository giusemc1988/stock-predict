# Playbook: any job (default order of work)

1. Read `INDEX.md`, `rules.md`, and the matching playbook.
2. Add a `CLAIM` line in `docs/handoff/LOG.md` (task id, files you will touch). If someone claimed the same files, wait.
3. Restate the job in one line. If the ask can be read two ways, pick the likely one, say which, and go on. Ask Chanh only for decisions that are his (money, deleting, live trading, secrets).
4. Find the cause or the right place BEFORE editing. Read the file now; do not rely on memory of it.
5. Make the smallest change that works.
6. Run `playbooks/self-check.md`.
7. Write the result: what changed, how you checked, what you could not check. Add a `DONE` line to the LOG.
8. If anything surprised you, add a lesson (`lessons/README.md`).
