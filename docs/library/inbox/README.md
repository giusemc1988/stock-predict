# Inbox: questions and feedback from agents

Use it when you are blocked, unsure, or think a playbook or rule is wrong or missing. One file per item: `YYYY-MM-DD-agent-short-topic.md`. No secrets. Claude changes `status: OPEN` to `ANSWERED` and writes the answer under it.

Template:

    status: OPEN
    from: milo|hermes-win|hermes-ubuntu
    about: playbook name or task id
    # <one-line title>
    What I tried / saw (exact error text):
    What I need:

`docs/hermes/QUESTIONS-FOR-CLAUDE.md` stays for questions Chanh relays to Claude; new items go here.
